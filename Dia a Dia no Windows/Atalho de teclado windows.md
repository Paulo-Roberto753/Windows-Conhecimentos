# 1. Atalhos básicos do Windows

| Atalho | Função |
|---|---|
| `Win + E` | Abrir Explorador de Arquivos. |
| `Win + R` | Abrir Executar. |
| `Win + I` | Abrir Configurações. |
| `Win + D` | Mostrar a área de trabalho. |
| `Win + L` | Bloquear o computador. |

# 2. Atalhos para suporte técnico

| Atalho | Função |
|---|---|
| `Ctrl + Shift + Esc` | Abrir Gerenciador de Tarefas. |
| `Ctrl + Alt + Del` | Abrir tela de segurança do Windows. |
| `Win + Pause` | Abrir informações do sistema. |
