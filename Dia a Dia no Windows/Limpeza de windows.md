## 🛠️ Comandos de Manutenção do Windows

| Comando | Função |
|---|---|
| 🗂️ `temp` | Acessar arquivos temporários do Windows. |
| 📁 `%temp%` | Acessar arquivos temporários do usuário. |
| ⚙️ `prefetch` | Acessar dados de pré-carregamento de programas. |
| 🧹 `cleanmgr` | Abrir a Limpeza de Disco do Windows. |
| 🔍 `sfc /scannow` | Verificar e reparar arquivos do sistema. |
| 💽 `chkdsk C: /scan` | Verificar erros no sistema de arquivos do disco. |

> 💡 **Dica:** Para executar os comandos de acesso, pressione `Win + R`, digite o comando e pressione Enter.

> ⚠️ **Atenção:** Não é recomendado apagar rotineiramente os arquivos da pasta `Prefetch`.
