
# 1. Atalhos básicos do Windows

| Atalho | Função |
|---|---|
| `Win + E` | Abrir Explorador de Arquivos. |
| `Win + R` | Abrir Executar. |
| `Win + I` | Abrir Configurações. |
| `Win + D` | Mostrar a área de trabalho. |
| `Win + L` | Bloquear o computador. |
| `Win + S` | Abrir pesquisa do Windows. |
| `Win + X` | Abrir menu de ferramentas administrativas. |
| `Win + A` | Abrir configurações rápidas. |
| `Win + V` | Histórico da área de transferência. |
| `Win + P` | Configurar projeção de tela. |

# 2. Atalhos para suporte técnico

| Atalho | Função |
|---|---|
| `Ctrl + Shift + Esc` | Abrir Gerenciador de Tarefas. |
| `Ctrl + Alt + Del` | Abrir tela de segurança do Windows. |
| `Win + Pause` | Abrir informações do sistema (em versões compatíveis). |
| `Win + R` | Abrir comandos de execução. |
| `Alt + Tab` | Alternar entre janelas. |
| `Alt + F4` | Fechar janela ou aplicativo. |
| `Win + Ctrl + Shift + B` | Reiniciar o driver gráfico. |

# 3. Atalhos para gerenciamento de janelas

| Atalho | Função |
|---|---|
| `Win + ↑` | Maximizar janela. |
| `Win + ↓` | Minimizar ou restaurar janela. |
| `Win + ←` | Organizar janela à esquerda. |
| `Win + →` | Organizar janela à direita. |
| `Win + Tab` | Abrir visão de tarefas. |
| `Win + M` | Minimizar todas as janelas. |
| `Win + Shift + M` | Restaurar janelas minimizadas. |

# 4. Atalhos para arquivos e pastas

| Atalho | Função |
|---|---|
| `Ctrl + C` | Copiar. |
| `Ctrl + X` | Recortar. |
| `Ctrl + V` | Colar. |
| `Ctrl + Z` | Desfazer. |
| `Ctrl + A` | Selecionar tudo. |
| `Ctrl + S` | Salvar. |
| `F2` | Renomear arquivo ou pasta. |
| `F5` | Atualizar janela. |
| `Shift + Delete` | Excluir permanentemente, sem passar pela Lixeira. |
| `Alt + Enter` | Abrir propriedades do arquivo selecionado. |

# 5. Atalhos para diagnóstico e produtividade

| Atalho | Função |
|---|---|
| `Win + R` → `cmd` | Abrir Prompt de Comando. |
| `Win + R` → `devmgmt.msc` | Abrir Gerenciador de Dispositivos. |
| `Win + R` → `services.msc` | Abrir Serviços do Windows. |
| `Win + R` → `eventvwr.msc` | Abrir Visualizador de Eventos. |
| `Win + R` → `diskmgmt.msc` | Abrir Gerenciamento de Disco. |
| `Win + R` → `msconfig` | Abrir Configuração do Sistema. |
| `Win + R` → `appwiz.cpl` | Abrir Programas e Recursos. |
| `Win + R` → `ncpa.cpl` | Abrir Conexões de Rede. |
| `Win + R` → `sysdm.cpl` | Abrir Propriedades do Sistema. |
| `Win + R` → `mmsys.cpl` | Abrir configurações de som. |
